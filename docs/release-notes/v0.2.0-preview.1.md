# v0.2.0-preview.1

## Summary

This preview runs Squirix nodes on a dedicated socket server with separate listeners for client traffic, peer traffic and management.

Still an early preview — not production-ready.

## Changes

- Breaking: embedded applications start nodes through `SquirixServer.StartAsync`
- Breaking: configure client and management TLS certificates with `SQUIRIX_TLS_CERTIFICATE_PATH` and `SQUIRIX_TLS_CERTIFICATE_PASSWORD`
- Breaking: health and metrics use the management origin configured by `SQUIRIX_MANAGEMENT_URI`
- Breaking: upgrade all cluster members together for the new binary mTLS peer protocol
- Console samples for shared typed caches and HybridCache backed by Squirix

## Install

- `dotnet add package squirix --version 0.2.0-preview.1`
- `dotnet add package squirix.extensions.caching --version 0.2.0-preview.1`
- `dotnet add package squirix.server --version 0.2.0-preview.1`
- `dotnet tool install --global squirix.server.tool --version 0.2.0-preview.1`
